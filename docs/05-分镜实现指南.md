## 一、先定三件事，再写一行代码

很多人卡在"怎么实现分镜"，是因为一开始就想成做 App。这本书的实现只要想清三件事：

**1. 一页 = 一个全屏区块，翻页 = 横向位移**
不要路由、不要分屏、不要滚动。整本书就是 N 个 `position:absolute` 的 section 排成一条横线，靠 `translateX` 移动。屏幕上永远只有一页。

**2. 每一页不是"模板"，是"剧本"**
同样一页"3 + 5 = 6"，如果是模板，你只能控制它出现在哪；如果是剧本，你能控制它先出现还是后出现、打字出来还是直接显示、停顿三秒还是五秒。

**停顿是这本书的主角。** 模板做不出停顿。

**3. 书会自己动，靠的是状态，不是动画库**
"书自己翻回去"不是某种炫技动效，而是状态机判定"这个孩子卡住了，我该带他回上一页"，然后调用同一个翻页函数。**动画只是结果，决策才是 agent。**

## 二、技术选型

| 需求 | 选什么 | 理由 |
|---|---|---|
| 框架 | Vite + React + TS（正式）；纯 HTML（原型/答辩兜底） | 一学期项目够用，静态部署零运维 |
| 翻页 | CSS `transform` + `transition` | 不需要动画库，一行 transition 就够 |
| 逐字 / 浮现 | 拆字符成 `<span>` + `opacity` | 比打字机库简单，中文按字拆分天然合适 |
| 手写批注 | 楷体 + 逐字浮现（进阶可用 SVG 描边动画） | 先做便宜的 |
| 声音 | Web Speech Synthesis（`speechSynthesis`） | 免费、离线、无版权 |
| 内容 | 独立 JSON + Zod 校验 | 改文案不改代码 |
| 动效曲线 | `cubic-bezier(.4,0,.2,1)`，时长 500–750ms | 慢一点才像翻书 |

**不建议**：Framer Motion / GSAP（对这本书来说过重，且答辩时讲不清"为什么用它"）。

## 三、数据结构：一页是一份剧本

```json
{
  "id": "p6",
  "painting": "p6.webp",
  "text": ["3 + 5", "它写：6"],
  "sideNote": "你知道它怎么想的吗？",
  "beats": [
    { "at": 500,  "do": "fadeIn", "target": "q1" },
    { "at": 1500, "do": "fadeIn", "target": "a1" },
    { "at": 4600, "do": "typeNote", "target": "n1", "each": 70 }
  ],
  "onEnter": ["markSeen:p6"],
  "noBubbles": true
}
```

字段只有五类：**画、正文、页边批注、节拍表、进入时要做的事**。

`beats` 是核心。`at` 是毫秒偏移，`do` 是动作名，动作只有五个：

| 动作 | 作用 |
|---|---|
| `fadeIn` | 元素淡入 |
| `type` | 逐字打出 |
| `typeNote` | 页边批注逐字浮现（楷体，慢一点） |
| `hold` | 什么都不做（**这一条最重要**） |
| `pageAction` | 触发书自己的动作，如 `flipBack:p7` |

`hold` 单独成为一种动作，是为了让"停顿"变成可以写进内容的东西。p6 的那三秒安静，价值高于任何动效。

## 四、翻页：三十行写完

```ts
const pages = document.querySelectorAll('.pg');
let cur = 0;

function go(n: number, mode: 'normal' | 'back' = 'normal') {
  if (n < 0 || n >= pages.length || n === cur) return;
  clearTimers();                       // 关键：切页必须清掉上一页残留的 setTimeout
  pages.forEach((p, i) => {
    p.style.transitionDuration = (mode === 'back' ? 520 : 720) + 'ms';
    p.classList.toggle('cur', i === n);
    p.classList.toggle('past', i < n);
  });
  cur = n;
  setTimeout(() => runBeats(n), 260);  // 等翻页动画过半再开演
}
```

```css
.pg { position:absolute; inset:0; transform: translateX(100%);
      transition: transform .72s cubic-bezier(.4,0,.2,1); }
.pg.cur  { transform: translateX(0); }
.pg.past { transform: translateX(-100%); }
```

就这么多。**唯一的坑是 `clearTimers()`**：不写的话，快速连点两下会把两页的演出叠在一起。

### "书自己翻回去"怎么做

不是倒放动画，而是**换一个进入方向**：

```css
@keyframes slideFromLeft {
  from { transform: translateX(-38%); opacity:.35; }
  to   { transform: translateX(0);    opacity:1; }
}
.pg.backIn { animation: slideFromLeft .52s cubic-bezier(.4,0,.2,1); }
```

`go(2, 'back')` 时给目标页加上这个类。视觉上它是"从左边滑过来"，读起来就是**你在往回翻**。

配合一句文案「我翻回了练习册」，这个动作就成立了。**动作 + 一句话 = agent 的主动性。**

## 五、逐字浮现：中文按字拆

```ts
function reveal(el: HTMLElement, each = 55) {
  const txt = el.dataset.t!;
  el.textContent = '';
  el.style.opacity = '1';
  [...txt].forEach((ch, i) => {
    const s = document.createElement('span');
    s.textContent = ch;
    s.style.opacity = '0';
    s.style.transition = 'opacity .3s ease';
    el.appendChild(s);
    timers.push(setTimeout(() => { s.style.opacity = '1'; }, i * each));
  });
}
```

要点：

- **中文用 `[...txt]` 拆**，标点和换行也算一个字符，节奏自然
- 批注比正文慢（70ms/字 vs 50ms/字），像真的在写
- 父元素 `white-space: pre-wrap`，`\n` 就换行

**为什么不用打字机库**：它的光标闪烁会破坏"安静"。这本书要的是文字慢慢出现，不是有人在打字。

## 六、关卡：这个"智能"只有一行代码

```ts
function ask(a: number, b: number) {
  const answer = a + a;                  // ← 它的全部办法
  screen.textContent = `${a} + ${b} = ${answer}`;
  screen.classList.toggle('wrong', a + b !== answer);
}
```

练习册上全是 `a + a`，所以它学到的规律就是"第一个数加它自己"。这一行代码：

- `1+1` → 2，对
- `9+9` → 18，对
- `3+5` → 6，错（应该 8）
- `7+2` → 14，错得离谱（应该 9）

**答辩时这一行就是杀手锏**：孩子觉得它有想法、有脾气、会犯糊涂，实际上它只有一行。这正是机器学习最好的注脚——**看起来像智能的东西，往往是极简规则加上大量数据的结果。**

建议在页面上留一句可点开的小字：`它的全部办法 = a + a`。评委一定会点。

## 七、p6 那一页怎么实现"沉默"

这一页技术上是全章最简单的，设计上是最难的：

```json
{
  "id": "p6",
  "text": ["3 + 5 = 6"],
  "beats": [
    { "at": 500,  "do": "fadeIn", "target": "equation" },
    { "at": 1500, "do": "hold",   "ms": 3000 },
    { "at": 4500, "do": "typeNote", "target": "note" }
  ]
}
```

实现上没有难点，难点是**忍住不做事**：

- 不加气泡按钮
- 不加"想好了吗"的提示
- 不加进度条
- 不加音效

原型里你可以验证：三秒的空白，孩子会抬头看你。这是整章唯一一次他真的在想。

## 八、声音（可选，但建议做）

```ts
function speak(text: string) {
  if (!speechSynthesis) return;
  const u = new SpeechSynthesisUtterance(text);
  u.lang = 'zh-CN';
  u.rate = 0.92;      // 比正常慢一点
  u.pitch = 1.02;
  speechSynthesis.cancel();      // 翻页必须先取消，否则两页声音叠在一起
  speechSynthesis.speak(u);
}
```

三条硬规矩：

1. **翻页前必须 `cancel()`**
2. 朗读只念"正文"，不念"页边批注"——批注是给你看的，不是给你听的
3. 全局可关闭，关闭后批注必须自带字幕效果（它本来就是文字，天然满足）

**不要把演示押在语音上**。教室环境吵，浏览器音色也不统一。

## 九、分阶段计划

| 阶段 | 产出 | 验收 | 工作量 |
|---|---|---|---|
| S1 | 静态翻页，10 页文案就位（无动画） | 能读完整个故事 | 0.5 天 |
| S2 | beats 演出引擎 + `hold` | p6 的沉默成立 | 1.5 天 |
| S3 | 逐字浮现 + 页边批注 | p7 的"翻回去"成立 | 1 天 |
| S4 | 关卡 | 孩子能连试 5 道以上 | 1.5 天 |
| S5 | 声音 + 音效 + 打磨 | 全程无卡顿 | 1 天 |

**顺序不能反**。S1 做完就应该拿给人读一遍——如果纯静态都读不下去，动效救不了它。

## 十、会踩的坑

| 坑 | 表现 | 解法 |
|---|---|---|
| 定时器没清 | 快速翻页时两页文字叠在一起 | 每次 `go()` 先 `clearTimers()` |
| 动画期间可点击 | 连点翻过两页 | 翻页锁 300ms |
| 中文逐字断行 | "3 + 5" 被拆到两行 | 算式类用整块 fadeIn，不逐字 |
| 字号写死 px | 平板上字太小 | 根字号用 `clamp()`，内部用 `em` |
| 楷体在部分安卓缺失 | 批注变成黑体，"手写感"没了 | 声明 `KaiTi, STKaiti, "Kaiti SC", serif` 三级回退 |
| 插画未就位时页面太空 | 演示效果差 | 先用 SVG 几何占位，别用纯空白 |
| 把所有内容写进组件 | 改一句话要改代码 | 内容全部走 JSON |

## 十一、原型能验证什么、不能验证什么

**能验证**

- 翻页节奏对不对
- p6 的三秒沉默是否成立
- "书翻回去"这个动作读不读得懂
- 关卡会不会让孩子想连试五道

**不能验证**

- 插画风格（原型是几何占位）
- 朗读语速
- 真实孩子的反应（必须找人试）

**下一步最该做的**：拿这个原型找 2 个孩子读一遍，只观察两件事——**p6 他停了多久，关卡他试了几道**。这两个数字决定这本书成不成立。
