## 1. 产品概述

### 1.1 定位

> 不是"绘本 + 一个问答框"，而是**这本书自己会等你**。

孩子翻开它，它开始讲；孩子停住了，它就不念了；孩子答错了，它把页面往回翻。

### 1.2 要解决的问题

儿童 AI 科普读物完成了"概念降维"，却没完成"困惑承接"——孩子读的时候那一瞬间的"等等，为什么？"，书上没有地方可以放。

### 1.3 三个层次（本产品的验收标尺）

| 层 | 表现 | 是不是伴读 |
|---|---|---|
| L1 读给你听 | 念文字、翻页 | 不是，这是有声书 |
| **L2 陪你读** | **会停、会等、会自己翻回去** | **是** |
| L3 懂你 | 记得你、因你而变 | 是，且是加分项 |

**判断标准只有一句：这本书会不会等。** 会等就是伴读，不会等就是幻灯片。

### 1.4 不做什么

家长端、账号体系、多章节选择、积分与勋章、社交分享、付费、实体角色、动画人物。

## 2. 形态设计（本版核心）

### 2.1 谁在说话

**不是书里的某个角色，是这本书本身。**

它没有名字、没有脸、没有固定位置。声音从纸面传来。孩子对自己说"这本书在跟我说话"，而不是"书里有个小人在跟我说话"。

这个选择牺牲了亲和力，换来两件事：

1. **没有角色就没有出戏**——不用维护一个形象的声音、性格、口头禅
2. **书是唯一能同时当"媒介"和"记忆"的载体**——角色会离开，书会留着

### 2.2 只有书能做的四个动作

这是"书即 agent"的全部证据。**这四件事，任何聊天框都做不到。**

| 动作 | 实现 | 为什么只有书能做 |
|---|---|---|
| **它会沉默** | 整页只有一行字，或一句话写到一半停下 | 聊天框永远在等输入，书可以什么都不给 |
| **它会自己翻回去** | 从左侧滑入上一页，配一句"我们回第三页看看" | 角色不能翻书，书可以 |
| **它会改变自己的排版** | 字变小、行距变松、整页明度降低 | 排版是书的呼吸，不是 UI 的状态 |
| **它会在页边留批注** | 手写体浮在空白处，明天翻回来还在 | 角色留不下痕迹，书本身就是痕迹 |

**其中"翻回去"是主动性最硬的证据**，答辩时优先演示这个。

### 2.3 排版即表情

没有脸，情绪只能靠排版。这是本产品最重要的一条设计规范。

| 状态 | 排版表现 |
|---|---|
| 平静讲述 | 正文 1.18em，行距 1.95，字距 .05em |
| 思考 / 犹豫 | 字号缩小 8%，行距放大到 2.3，句末省略号 |
| 确定了 | 字号放大 6%，行距收紧到 1.7 |
| 难过 / 沉默 | 整页明度降 12%，文字色变浅，大量留白 |
| 等你回答 | 只留一行小字，其余全空，**不加任何按钮** |

**禁止**：用 emoji、用颜色闪烁、用抖动、用"正在输入…"。

### 2.4 声音

- Web Speech Synthesis，`rate 0.92`，语气偏温和
- **只念正文，不念页边批注**——批注是看的，不是听的
- 全局可关闭，关闭后功能不缺失（批注本来就是文字）

### 2.5 这个形态失去什么

必须认清，否则会在答辩时被问倒：

| 失去 | 影响 | 补偿方式 |
|---|---|---|
| 没有形象 | 做不了周边、封面角色、宣传主视觉 | 用"纸的质感"当视觉资产 |
| 没有身体动作 | 缺少"陪着你"的即时感 | 靠留白、停顿、翻回去补 |
| 亲和力弱 | 孩子第一眼不如卡通角色亲近 | 靠语气（短句、不夸、会承认不懂） |

## 3. 用户与场景

### 3.1 用户画像

**主用户：阿芽，8 岁，小学二年级**

- 认识常用汉字，能读短句，遇到长词会跳过
- 好奇心强，但注意力约 10–15 分钟
- 不会打字，能点选、能拖、能说话
- 讨厌被说教，被当成小孩时会立刻关闭兴趣

**次级用户：家长**

- 关心两件事：内容是否安全、孩子是否真的学到了
- 要求"打开就能用，不用配置"

**评委 / 教师**

- 会追问："这和直接用 ChatGPT 读绘本有什么区别？"

### 3.2 核心场景

教室后面多了一个黑盒子，老师说它什么题都会做。它把练习册上一百道题全做对了，一道都没错。

老师拿出一张新卷子。第一道是 3 + 5。它写 6。

书在这里停住。整页只有那一行算式，没有按钮，没有提示。等孩子自己想。

想不通的时候，书会自己往回翻——翻到那本练习册，一百道题，两个数全都一样。

**这个场景就是产品本身**：不是"讲一个故事"，而是"在一次停顿里，让孩子和书一起想明白一件事"。

### 3.3 场景对设计的约束

| 特征 | 约束 |
|---|---|
| 孩子一个人读 | 没有老师在旁，书必须自己完成引导 |
| 注意力 10–15 分钟 | 单章 8–12 分钟可读完 |
| 不会打字 | 全靠点选、拖拽；语音为可选增强 |
| 常在地铁 / 床上 / 沙发上 | 单手持平板，横屏，翻页动作要轻 |

## 4. 信息架构

```
进入页
 └── 封面
      └── 正文 p1 – p10（横向翻页，一屏一页）
           ├── 每页：插画 / 正文 / 页边批注
           ├── p9：递题关卡（同页内，不跳转）
           └── p10：收束 + 批注留存
```

**单章 10 页，8–12 分钟。** 无目录、无跳转、无菜单——保持"读一本书"的线性感。

## 5. 功能需求

### 5.1 F1 阅读器

| 项 | 规则 |
|---|---|
| 翻页 | 左右滑动 / 点击两侧 / 方向键。切换 720ms，`cubic-bezier(.4,0,.2,1)` |
| 页面构成 | 插画层（占 70%）+ 文字层（正文 ≤ 3 行，每行 ≤ 12 字）+ 批注层（页边） |
| 文字出现 | 逐字浮现，正文 50ms/字，批注 70ms/字 |
| 朗读 | 进入页面自动朗读正文，可全局关闭 |
| 朗读打断 | 孩子操作立即停止，不抢话 |
| 进度 | 自动记录页码，下次进入提示"上次读到……" |

**验收**：翻页无白屏；快速连点不叠页；关闭朗读后功能不缺失。

### 5.2 F2 书的三个动作

本节是 agent 属性的实现清单。

**F2.1 沉默（`hold`）**

- 在节拍表里是一个独立动作，参数为毫秒数
- 沉默期间**页面不响应任何提示性动效**（不加"想看答案吗"）
- 用于 p6，时长 3000ms

**验收**：p6 进入后，3 秒内屏幕上不发生任何变化。

**F2.2 翻回去（`flipBack`）**

- 目标页从**左侧**滑入（520ms），配一句"我们回第三页看看"
- 视觉上读起来是"往回翻"，不是"跳到某页"
- 触发条件：当前页目标未达成 + 孩子停滞 > 8 秒，或孩子答错两次

**验收**：孩子能说出"书翻回去了"。

**F2.3 改排版（`setTone`）**

- 五种状态，见 2.3 节
- 切换用 600ms 过渡，不做瞬变

**验收**：同一段文字在"平静"与"难过"两种状态下，孩子能看出不一样。

### 5.3 F3 页边批注

- 楷体，位于页面右侧下方，最大宽度 40%
- 逐字浮现，70ms/字
- **默认永久保留**：孩子下次打开这一页，批注还在
- 全章批注 ≤ 6 条，宁少不多

**验收**：p10 的批注在第二天打开时仍在原位。

### 5.4 F4 气泡提问（轻量版）

**本期只做 5 个，不做全章。**

- 每页最多 2 个气泡，出现在页脚
- 点击后书以"文字逐字浮现"回答，不用对话框
- 问题以儿童口吻写，答案人工撰写，不走模型

**为什么只做 5 个**：气泡是"配角"。做多了这本书就变成答题游戏。第一版只验证"孩子愿不愿意点"。

### 5.5 F5 递题关卡（p9）

- 屏幕上是黑盒子，下面是 5 张题卡
- 点一张，卡片滑到盒子上，它给出答案
- **它的全部逻辑只有一行**：`answer = a + a`
  - `1+1` 对、`9+9` 对
  - `3+5` 错成 6、`7+2` 错成 14
- 无对错判定、无奖励、无进度条

**页面留一行可点开的小字**：`它的全部办法 = a + a`。这是答辩证据，评委一定会点。

**验收**：孩子至少试 5 道；别人问他"它怎么想的"，他能说出来。

### 5.6 F6 问题本

- 数据：孩子说"我不懂"的地方 + 超纲问题
- 展示：p10 展开，"阿芽的小本子"，手写体卡片
- 文案："这些我还答不上来。明天我们一起看。"
- 不做删除、不做编辑

**这是 L3（懂你）唯一的入口**，本期只做"记录 + 展示"，不做跨会话推理。

### 5.7 F7 断点续读

进入时若 `page > p1`，封面下方一行小字"上次读到它把题答错了那页"，点击直达。

## 6. 伴读规范

### 6.1 介入决策表

每次翻页、每轮对话结束后按顺序判断：

| 条件 | 动作 |
|---|---|
| 当前页是静默页（p6） | **沉默**，不做任何提示 |
| 当前页是锚点页，目标未达成 | 用一句话提问 |
| 当前页是锚点页，目标已达成 | **保持沉默，允许直接翻页** |
| 孩子停滞 > 8 秒 | 书自己往回翻，或给半句提示 |
| 孩子连续 2 次答偏 | 换说法（见 6.2） |
| 孩子问超纲问题 | 记入本子 + 一句话交代 |

**"保持沉默"是设计的一部分**，不是遗漏。它证明书在判断。

### 6.2 重讲策略（禁止重复同一句话）

1. 第一遍：用本页已有的东西讲
2. 第二遍：换一个生活里的例子
3. 第三遍：让他自己动手（推进关卡）
4. 第四遍：诚实停下——"这个有点难，我们先记住它"

### 6.3 语调

- 句长 ≤ 20 字，一次 ≤ 2 句
- 不用"首先、其次、总之"
- 不用感叹号连发
- 每 3 轮至少把一个问题抛回去
- 涉及"机器出错"时，落点永远是"可以变好"，不制造对立
- **可以说"我也不知道"**，说完要记进本子

## 7. 内容规范

- 每页正文 ≤ 3 行，每行 ≤ 12 字
- 正文是故事，批注是书在说话——**正文不出现"我"，批注可以说"我"**
- 全章不用感叹号
- 术语降维表见需求分析第 9 节

### 7.1 术语策略（两段式）

**正文里不出现术语，章末必须命名。** 顺序是「先懂，再命名」。

| 位置 | 规则 |
|---|---|
| 故事正文（p1–p10） | **不出现**过拟合、泛化、训练集、测试集、模型、算法、人工智能、数据 |
| **章末命名页（p11）** | **必须出现**术语，配拼音、一句儿童话解释，并注明"记不住也没关系" |
| 自由对话 | 平时不用术语；**孩子主动问"这叫什么"时，直接告诉他** |
| 书架卡片 | 显示中文主题词，不显示 `overfitting` 这类英文 |

**为什么不在正文里说**：7–9 岁读到不认识的词会停下来问，故事就断了；而且记不住。

**为什么必须有一页命名**：否则孩子读完不知道自己在学 AI，家长和评委也找不到锚点。命名页放在故事结束之后，孩子已经懂了，只是给它一个名字——这是儿童博物馆的做法：展厅里不写"牛顿第二定律"，出口那块牌子写"你刚才玩的是惯性"。

**命名页文案（定稿）**

```
它有个名字

你刚才看的那件事，有一个名字。

        过拟合
     guò nǐ hé

  它把练习册记得太熟了。
  换一道没见过的题，就不会了。

  记不住这个词也没关系。
  记得「别用他做过的题考他」就够了。
```

## 8. 视觉规范

### 8.1 设计原则

童趣不等于花花绿绿。这一章发生在教室，白天，但孩子通常在晚上读。

**基调：像一本用了很多年的旧书，纸是暖的，字是深的。**

三条规则：
1. 纸色打底，不用纯白；文字用暖褐，不用纯黑
2. 所有形状圆角，最小 8px
3. 动效一律慢（≥500ms），不用弹跳、闪烁

### 8.2 色板

| 用途 | 色名 | 色值 | 说明 |
|---|---|---|---|
| 纸面 | 奶油白 | `#FFF8EC` | 全屏底色，不用纯白 |
| 正文 | 暖褐 | `#3E2C23` | 不用纯黑，降低对比疲劳 |
| 次要文字 | 浅褐 | `#8A7A6A` | 小字标签、页码 |
| 批注 | 赭石 | `#8A6A4E` | 手写体专用 |
| 对勾 | 草绿 | `#6E9B4E` | 练习册的批改 |
| 错误 / 冲突 | 砖红 | `#C0564D` | 全章仅出现在 p5 的错答 |
| 点缀 | 芥末黄 | `#E8B94A` | 极少量，不超过画面 5% |

### 8.3 字体

| 层级 | 字体 | 字号 | 行高 |
|---|---|---|---|
| 书名（封面） | 站酷快乐体 / 得意黑 | 32–40px | 1.4 |
| 正文 | 思源黑体 Regular | 20–22px | 1.95 |
| 批注 | 楷体（KaiTi / STKaiti / Kaiti SC 三级回退） | 18px | 1.95 |
| 算式 | 等宽字体 | 大号 | 1.4 |

正文 20px 起是硬要求——7–9 岁的阅读字号不能按成人标准。

### 8.4 插画

风格、prompt、工作流见 `06-插画出图手册.md`。四条底线：

1. **插画里不画任何文字**，全部代码层叠加
2. 风格段定稿后冻结，只换 subject
3. p3 与 p7、p1 与 p10 复用同一张底图
4. **满版出血**：插画铺满整页，文字压在画面预留的留白处。**不做"上图下文"的插图框**——那看起来像 PPT，不像书。出图时在 prompt 里写明"画面下方留出安静的空地"

### 8.5 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 翻页 | 720ms | cubic-bezier(.4,0,.2,1) |
| 翻回去 | 520ms | 同上 |
| 逐字（正文） | 50ms/字 | ease |
| 逐字（批注） | 70ms/字 | ease |
| 排版状态切换 | 600ms | ease-in-out |

禁止：弹跳、闪烁、粒子、快节奏音效、光标闪烁。

## 9. 第 2 章内容设计

完整正文、分镜、台词、批注见 **`04-第2章内容稿-它背下了整本练习册.md`**。本节只保留产品侧要点。

**知识点**：过拟合。儿童话说——它把答案记住了，可没学会怎么算。

**教学目标**

| 编号 | 目标 |
|---|---|
| G1 | 它在练习册上全对，不代表它真的会 |
| G2 | 它学的是练习册里的规律，练习册太整齐，规律就学窄了 |
| G3 | 要拿它没见过的题考它，才知道它会不会 |

**三句不能改的话**

1. p6 那页整页只有 `3 + 5 = 6`，**不给任何提示**
2. p8「它学的不是加法，它学的是这件事。」
3. p10「它不是不会。它只是没见过的题，一道也没有。」

## 10. 技术方案

### 10.1 架构

```
┌─ 内容层 ────────────────────────────────┐
│  chapter.json  页 / 文案 / 批注 / 节拍表   │
└─────────────────────────────────────────┘
              ↓ 加载并校验（Zod）
┌─ 演出层 ────────────────────────────────┐
│  beats 时间轴：fadeIn / type / hold / …  │
└─────────────────────────────────────────┘
              ↓ 状态与事件
┌─ 书的意志 ──────────────────────────────┐
│  页码 / 停滞时长 / 试过几道 / 达成状态     │
│  → 决定：沉默、翻回去、换排版、记本子       │
└─────────────────────────────────────────┘
```

**关键判断**：第三层才是 agent，前两层只是渲染。

**内容不是线性序列，是可调度的片段。**

十页故事是"主线片段"，但 agent 手上还有若干**补充片段**（换一个说法、再想一次、回头看看）。它根据孩子的反应决定要不要插进去。

所以两个孩子读同一章，走到的路径可能不一样——**这不是 bug，这是产品**。判断标准很直接：如果所有孩子读到的内容完全一致，那它就是一本会翻页的书，不是教师。

**本期落地的第一条调度规则**（用来证明机制存在，不求多）：

| 观察 | 判断 | 行动 |
|---|---|---|
| 离开 p8 时停留 < 3.5 秒 | 太快，多半只是翻过去了 | 插入「换一个说法」，用生活例子重讲一遍 |
| 离开 p8 时停留 ≥ 3.5 秒 | 他在琢磨 | 不打扰，直接进关卡 |

这条规则的价值不在规则本身，而在**它证明了内容是被调度的，不是被播放的**。后续增加规则只是往这张表里加行。

### 10.2 选型

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Vite + React + TS | 静态部署、零运维 |
| 翻页 | CSS transform + transition | 不需要动画库 |
| 逐字 | 拆字符 + opacity | 中文按字拆天然合适 |
| 内容 | JSON + Zod | 改文案不改代码 |
| 声音 | Web Speech Synthesis | 免费、离线 |
| 模型 | 已接入（OpenAI 兼容，千问 / DeepSeek 均可） | 未配 key 自动降级，不影响阅读 |

### 10.3 降级

| 失效 | 影响 | 方案 |
|---|---|---|
| 语音不可用 | 无法朗读 | 批注与正文本身就是文字，功能不缺失 |
| 动画卡顿 | 逐字变跳字 | 降级为整块淡入 |
| 无网络 | 无 | 全静态，无影响 |

### 10.4 数据

localStorage 单键 `book.ch02.state`，存页码、批注留存、问题本。不上传任何数据。

## 11. 埋点与验证

**埋点**：`page_view` / `page_dwell` / `agent_silent` / `agent_flipback` / `note_shown` / `bubble_click` / `card_tried` / `question_book_add`

**两个核心指标**（只这两个）

| 指标 | 目标 | 含义 |
|---|---|---|
| p6 停留时长 | ≥ 3 秒 | 这本书会不会等得住 |
| p9 试题数 | ≥ 5 道 | 它有没有勾起好奇心 |

其余指标都是参考，这两个不过，其他都白搭。

**验证方案**：2 个孩子读黄金样本（p6+p7）；4–5 个孩子做最终对照测试（本书 vs 静态绘本），问三个问题："它为什么把 3+5 答成 6？""它自己知道错了吗？""怎么才能让它答对？"

## 12. 里程碑

| 阶段 | 产出 | 闸口 |
|---|---|---|
| 0 定稿 | 形态 / 内容 / 书名确定 | 组内签字，改则砍项 |
| 1 黄金样本 | p6 + p7 真图真节拍 | **孩子停 ≥ 3 秒** |
| 2 全书灰模 | 10 页文字与节拍，灰块占位 | 自己读完没有想跳过的页 |
| 3 插画 + 引擎 | 10 页图 + 可翻可读 | 三张并排像同一画师 |
| 4 伴读 + 验证 | 三个动作 + 5 个气泡 | 对照测试通过 |

**分工（4 人）**

- A 内容与文案（节拍表、批注、气泡答案）
- B 视觉与插画（出图、后期、排版实现）
- C 引擎（翻页、节拍、状态机）
- D 关卡 + 测试 + 答辩材料

## 13. 风险

| 风险 | 等级 | 对策 |
|---|---|---|
| 被质疑"就是个电子绘本" | 高 | 演示 p6 的停顿与 p7 的翻回去，**这两个动作是唯一的证据** |
