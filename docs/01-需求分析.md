# 需求分析说明书

## 《等等，为什么？》

| 项目 | 内容 |
|---|---|
| 产品名 | **《等等，为什么？》** |
| 文档版本 | v2.0 |
| 编写日期 | 2026-11-15 |
| 本次范围 | 第 2 章《它背下了整本练习册》单章验证 |
| 目标用户 | 7–9 岁儿童（小学低中年级），及其家长 |
| 形态 | 网页，浏览器直接打开，平板横屏优先 |
| 项目性质 | 软件工程专业课程项目 |

> **v2.0 变更说明**：v1.0 设计了一个实体 AI 角色（床头旧台灯"点灯"）。该方案已废弃——它需要额外解释才成立，且只适配"机器学习"一篇。本版改为**书本身即 agent**，章节改为过拟合题材。相关旧内容稿一并作废。

## 1. 项目概述

### 1.1 背景

孩子的世界已经被 AI 包围：短视频会一直推他喜欢的东西，平板能画出他描述的画面，学校的摄像头会记录谁犯规。但孩子对这些"为什么会这样"的困惑，通常只有两种归宿——被大人用一句"它就是这样的"带过，或者干脆忘掉。

市面上的儿童 AI 科普读物大多面临同一个困境：**把成人概念翻译成儿童语言，但翻译完就结束了**。书是静态的，孩子的问题却发生在阅读的进行时。

### 1.2 参照作品分析

课程中另一小组完成了高完成度的 AI 科普绘本，其方法论值得继承：

- **选题公式**：儿童兴趣词 × AI 知识词 → 一个带冲突的故事标题
- **故事入口**：选在一个"异常时刻"，而不是一个概念定义
- **知识密度**：每篇只挂 1–2 个概念，不做灌输
- **呈现**：插画承担叙事，文字极少，留白充分

其局限也正是我们的机会：

| 维度 | 参照作品 | 本项目 |
|---|---|---|
| 内容 | 绘本页 + 极简文字 | 同一套内容方法论 |
| 提问那一刻 | 书无法回应 | **书自己停下来等** |
| 阅读节奏 | 固定 | **由孩子的反应决定** |
| 读完 | 即结束 | 一次动手验证 + 页边批注留存 |

### 1.3 产品定位

> 不是"绘本 + 一个问答框"，而是**这本书自己会等你**。

孩子翻开它，它开始讲；孩子停住了，它就不念了；孩子答错了，它把页面往回翻。

### 1.4 与"有声书""聊天机器人"的区别

这是本项目最核心的判断。

| 形态 | 表现 | 是不是伴读 |
|---|---|---|
| 有声书 | 念文字、自动翻页 | 不是 |
| 聊天机器人 | 你问，它答，答完就结束 | 不是 |
| **这本书** | **会停、会等、会自己翻回去、会在页边留字** | **是** |

判断依据只有一句：**这本书会不会等。**

去掉任何对话框，产品仍然成立——因为它从不靠"聊天"来证明自己。

## 2. 用户与场景

### 2.1 用户画像

**主用户：孩子，8 岁，小学二年级**

- 认识常用汉字，能读短句，遇到长词会跳过
- 好奇心强，但注意力约 10–15 分钟
- 不会打字，能点选、能拖、能说话
- 讨厌被说教，被当成小孩时会立刻关闭兴趣

**次级用户：家长**

- 关心两件事：内容是否安全、孩子是否真的学到了
- 要求"打开就能用，不用配置"

**评委 / 教师**

- 关注选题价值、技术真实性、是否有可验证的学习效果
- 会追问："这和直接用 ChatGPT 读绘本有什么区别？"

### 2.2 核心使用场景

教室后面多了一个黑盒子，老师说它什么题都会做。它把练习册上一百道题全做对了，一道都没错。

老师拿出一张新卷子。第一道是 3 + 5。它写 6。

**书在这里停住。** 整页只有那一行算式，没有按钮，没有提示，没有"想看答案吗"。孩子抬头看一眼，又低头看那一行字。

想不通的时候，书会自己往回翻——翻到那本练习册，一百道题，两个数全都一样。

孩子把五张题卡挨个试了一遍，看着它错得离谱。书在页边写下一行小字：下次你想知道一个人会不会，别用他做过的题考他。

**这个场景就是产品本身**：不是"讲一个故事"，而是"在一次停顿里，让孩子和书一起想明白一件事"。

### 2.3 场景对设计的约束

| 特征 | 约束 |
|---|---|
| 孩子一个人读，没有老师在旁 | 书必须自己完成引导，不能依赖外部提示 |
| 注意力 10–15 分钟 | 单章 8–12 分钟可读完，支持中途退出 |
| 不会打字 | 全靠点选、拖拽；语音为可选增强 |
| 常在床上、地铁、沙发上 | 单手持平板，横屏，翻页动作要轻 |
| 可能睡前读 | 音量适中，支持静音；配色不刺眼 |

## 3. 需求来源

1. **参照作品的缺口**：静态绘本丢失了"提问那一刻"，而那是阅读中认知价值最高的瞬间。
2. **儿童认知特点**：7–9 岁理解抽象概念依赖具体例子与可操作验证，纯讲解有效性低。
3. **AI 素养教育的目标**：不是记住术语，而是建立"AI 是学出来的、会出错、可以被改进"的基本认知。
4. **工程可行性**：一学期、3–5 人、零预算，必须把范围压到能做完且能演示。

## 4. 功能需求

### 4.1 功能结构

```
会说话的 AI 科普书 · 单章
├── 阅读层
│   ├── 绘本翻页（一屏一页）
│   ├── 逐字浮现
│   └── 朗读（TTS，可关）
├── 书的意志层
│   ├── 沉默（停在某页不动）
│   ├── 翻回去（从左侧滑入上一页）
│   ├── 改排版（字距/字号/明度的情绪表达）
│   └── 页边批注（手写体，永久留存）
├── 交互层
│   ├── 气泡提问（本期 5 个）
│   └── 递题关卡（p9）
└── 记忆层
    ├── 阅读进度
    └── 问题本
```

### 4.2 用例清单

#### UC-01 阅读绘本

- **参与者**：孩子
- **前置**：打开页面
- **主流程**：左右滑动翻页 → 插画淡入 → 正文逐字浮现 → 朗读本页（可关）→ 进入下一页
- **异常**：快速连点 → 翻页锁 300ms，不叠页
- **优先级**：Must

#### UC-02 书停下来等（p6）

- **参与者**：书（系统主动）
- **前置**：进入 p6
- **主流程**：显示 `3 + 5 = 6` → **3000ms 内不发生任何变化** → 之后页边浮现一句批注
- **异常**：孩子在沉默期间操作 → 不打断沉默，只暂停朗读
- **说明**：这是全书唯一一次完全静默，不加任何提示按钮
- **优先级**：Must

#### UC-03 书自己翻回去

- **参与者**：书（系统主动）
- **前置**：孩子停滞 > 8 秒，或连续答错 2 次
- **主流程**：上一页从**左侧**滑入（520ms）→ 配一句话"我们回前面看看" → 停在目标页
- **异常**：孩子手动翻页 → 取消自动动作
- **说明**：视觉上必须读作"往回翻"，不是"跳到某页"
- **优先级**：Must

#### UC-04 点击气泡提问

- **参与者**：孩子
- **前置**：当前页配置了气泡（全章仅 5 个）
- **主流程**：页脚浮现 1–2 个气泡 → 点击 → 书以逐字浮现回答 → 气泡收起
- **说明**：答案人工撰写，不走模型；不做全章覆盖，避免变成答题游戏
- **优先级**：Should

#### UC-05 递题关卡（p9）

- **参与者**：孩子
- **前置**：读到 p9
- **主流程**：屏幕上是黑盒子，下方 5 张题卡 → 点一张 → 卡片滑上去 → 它给出答案（`a + a`）→ 孩子继续试
- **异常**：同一张卡不可重复点
- **说明**：无对错判定、无奖励、无进度条。页面留一行可点开的小字 `它的全部办法 = a + a`
- **优先级**：Must

#### UC-06 页边批注留存

- **参与者**：孩子
- **前置**：读过带批注的页
- **主流程**：批注以手写体逐字浮现 → 关闭页面 → 次日打开 → 批注仍在原位
- **优先级**：Should

#### UC-07 查看问题本

- **参与者**：孩子
- **前置**：至少记录过 1 条
- **主流程**：p10 展开"阿芽的小本子" → 列出手写体卡片 → 书说"这些我还答不上来"
- **优先级**：Should

#### UC-08 中断续读

- **参与者**：孩子
- **前置**：上次未读完
- **主流程**：进入时封面下方一行小字 → 点击直达该页
- **优先级**：Should

### 4.3 优先级（MoSCoW）

| 级别 | 内容 |
|---|---|
| Must | 翻页阅读、逐字浮现、朗读、**沉默**、**翻回去**、递题关卡 |
| Should | 页边批注留存、气泡提问、问题本、中断续读、改排版（情绪） |
| Could | 语音输入、自由提问（接模型）、多章选择 |
| Won't | 家长端、账号、社交分享、积分、实体角色、动画人物 |

## 5. 非功能需求

### 5.1 性能

| 指标 | 要求 |
|---|---|
| 首屏加载 | < 2s |
| 翻页响应 | < 300ms |
| 逐字浮现 | 50ms/字（正文）、70ms/字（批注） |
| 连续翻页 | 不叠页、不丢动画 |

### 5.2 可用性

- 8 岁儿童无需指导可完成"翻页 → 点气泡 → 试题卡"三步
- 可点击元素 ≥ 44×44 px
- 全程不依赖打字
- 支持静音，静音后功能不缺失

### 5.3 内容安全

- 不出现暴力、恐怖、价值评判、医疗与法律建议
- 不引导孩子透露真实信息
- 不出现外链、广告、第三方跳转
- 涉及"机器出错"时，落点是"可以被改进"，不制造对技术的敌意

### 5.4 数据与隐私

- 所有状态存 localStorage，可一键清除
- 不采集设备标识，不做用户画像
- 语音识别（若启用）在本地完成，失败则不落盘

### 5.5 可维护性

- 页面内容、批注、气泡答案、节拍表全部走 JSON 配置
- 改一页文案不需要改代码

## 6. 约束、假设与风险

**约束**

1. 一学期，团队 3–5 人，无预算
2. 无稳定的儿童用户测试资源，只能做 2–5 人观察
3. 插画依赖 AI 生成 + 人工挑选，成本集中在风格统一

**假设**

1. 孩子在平板上阅读，横屏
2. 无需后端，纯静态部署

**已知风险**

| 风险 | 影响 | 对策 |
|---|---|---|
| 被质疑"就是个电子绘本" | 高 | 演示 p6 停顿与 p7 翻回去，这两个动作是唯一证据 |
| p6 立不住 | 高 | 黄金样本阶段先验，孩子停不足 3 秒就回去改 |
| 没有角色导致亲和力弱 | 中 | 靠语气与批注补；封面点明"这本书会等你" |
| 插画风格不统一 | 中 | 风格段冻结，p1/p3/p7 并排验收 |
| 做成答题游戏 | 中 | 气泡只做 5 个，关卡不给奖励 |
| 范围膨胀 | 中 | 定稿单为红线，任何新增先砍一个旧项 |

## 7. 范围界定

**本期做**：第 2 章《它背下了整本练习册》完整闭环——10 页绘本、沉默、翻回去、页边批注、5 个气泡、1 个递题关卡、问题本、断点续读。

**本期不做**：实体角色、账号、家长端、多章、积分、社交、自由接模型。

**理由**：单章闭环的完成度比多章半成品更能证明设计成立。

---

## 8. 验收标准

**产品层面**

1. 8 岁儿童在无指导下可独立完成全章，耗时 8–12 分钟
2. **p6 停留 ≥ 3 秒**
3. 全书至少 2 次"书主动做了一件事"（沉默、翻回去、改排版、留批注）
4. 翻回去的动画读起来是"往回翻"而非"跳转"
5. **p9 至少试 5 道题卡**
6. 批注在次日打开时仍在原位

**效果层面**（小样本，n=4–5）

7. 读完后能说出"它只记住了练习册上的答案"的比例 ≥ 60%
8. 能说出"要拿没见过的题考它"的比例 ≥ 40%
9. 对照纯静态绘本组，在"能否解释原因"上表现更好

**工程层面**

10. 断网可用
11. 内容与引擎分离，改文案不改代码

## 9. 术语降维表

面向儿童的文字必须遵守此表。左侧为禁止直接出现的表述。

| 不出现 | 换成 |
|---|---|
| 过拟合 | 它只记住了这一本练习册 |
| 泛化 | 换一道没见过的题 |
| 训练数据 | 它做过的那些题 |
| 测试集 | 它没见过的题 |
| 算法 | 它心里的办法 |
| 模型 | 那台会答题的机器 |
| 准确率 | 它答对了多少道 |
| 人工智能 | 会自己学的机器 |

**原则**：孩子在页面上读不懂的词，就不该出现在版面上。
